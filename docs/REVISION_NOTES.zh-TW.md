## 驗證邊界

48 人原型可檢查持久資料、結構差異及同源分層組裝，使用低擬真 SVG；正式像素圖層、動畫與遊戲生成器尚未完成。正式 UI 尺寸下的辨識度、各動作適配仍須依清單驗收，資料去重不能直接當成全部美術已完成。

場景經實際目視檢查才採用。一張新生成的雙層建築封面因外部街道仍有透視而退回，未收入此版；封面改用合格的雨天辦公室。舊稿可由 Git 歷史查閱，不再放在目前檔名下作製作參照。

文件及下載包由本版來源重建，完整性以 SHA256SUMS 驗證。此專案目前沒有可測試的正式 Godot 遊戲或美術匯入版本，此處不宣稱遊戲功能已完成。
