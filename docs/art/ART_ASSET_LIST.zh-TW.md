# 律師事務所模擬器｜美術設定與製作資源清單

版本：v0.1；搭配《遊戲設計文件與產品需求》及視覺簡報使用。

本文件是**可派工的美術需求表**。簡報附的概念圖用來確認風格、構圖、角色及城市差異；除非另有逐格驗收與交付，不把概念圖當成已完成的可直接匯入精靈、地圖格或動畫。本清單所有項目目前皆為「待製作」。

**範圍排除：不含音樂，也不含任何音訊製作；音樂由使用者自行完成，不重複估列。**

## 1. 統一美術方向

- **題材與氛圍：** 臺灣當代律師職場。低彩度木色、紙張、藍灰西裝與雨天窗景，保留早餐袋、飲水機、冷氣、案卷堆等生活細節。幽默來自工作與人物表情，不以華麗法庭奇觀為中心。
- **視角：** 2D 正交斜俯視，約三分之四俯視；同一遊戲不要混用等角菱形地板與正交32格網。
- **畫布：** 場景基準640×360，桌面預設1280×720；nearest濾波、整數倍縮放。文字與UI獨立，長寬比不同時留邊或重新排版。
- **像素密度：** 地圖格32×32；人物單格32×48。家具寬高採16或32的倍數；有意使用的16×16桌面物件需與同場角色比例一致。
- **人物：** 約三頭身、腳點對齊(16,44)。性別只影響外觀；不以服裝、膚色、年齡或性別直接表示能力高低。
- **光影：** 統一左上主光，每種材質約2–4階明暗；輪廓清楚、陰影以硬邊色塊處理，不使用平滑漸層、柔焦或抗鋸齒邊。
- **字體：** 繁體中文可讀性優先。建議原生字級12–16像素，重要中文至少16像素起測；字體授權與缺字覆蓋必須確認。像素風不等於文字必須糊。
- **畫面層次：** 地板 → 後牆／窗景 → 後排家具 → 人物與中景物件 → 前景遮擋 → 光影 → UI。可互動提示以程式疊加。

## 2. 數量怎麼計算

- 「工作項目」是CSV的一列；一列可包含一組圖示、模組或肖像，**不是一列等於一個PNG檔**。
- 「獨立基底」是需設計的不同外觀／構圖。變體、調色、狀態、導出影格另列，不與基底混加。
- 場景有15個獨立版型／構圖；可重用地板、家具、人物。四時段調色層不算四張新場景。
- 人物有18個身分基底：8個A類工作角色、10個B類事件／客戶角色。A類每基底48格、B類32格，共704個**動畫輸出影格槽位**；鏡像與重用可減少實際手繪量，但需逐方向驗收。
- 肖像18基底×6表情=108個表情輸出，不代表108個新角色。
- 十三特性各一個圖示基底；選取／禁用等狀態由UI疊加。
- 二十個存檔位只需一套可重用卡片模板；七日×四時段也只需一套格子模板。
- 概念圖、可編輯源檔、匯出PNG、合圖atlas與metadata是同一資產的不同交付物，不重複算作不同美術設計。

## 3. 人物動畫共用規格

簡報中的高細節時裝比例人物用來確認西裝、髮型、配件與性格；小型chibi研究才接近遊戲比例。正式遊戲人物需重新製作32×48、約三頭身精靈，不能把大人物圖直接縮小就視為完成稿。腳點仍固定(16,44)。

| Profile | 必要狀態 | 影格與方向 | 循環／時間建議 |
|---|---|---|---|
| A：主角／律師／老闆 | 待機、走路、寫狀、交談、疲倦 | 待機四向×2=8；走路四向×4=16；寫狀正／側兩向×4=8；交談四向×2=8；疲倦四向×2=8；總48格 | 待機約2fps、走路約6–8fps、寫狀約4fps、交談約3fps、疲倦約2fps；均可循環 |
| B：客戶／記者／醫師 | 待機、走路、交談 | 待機四向×2=8；走路四向×4=16；交談四向×2=8；總32格 | 同A相應狀態 |

四向定義為前、後、左、右；左右可由鏡像產生，但領帶、胸針、持物的方向要人工確認。每張單格32×48，角色腳點固定(16,44)，不隨動作上下飄移。A邏輯表8欄×6列=256×288，B邏輯表8欄×4列=256×192，以上是**不含padding的邏輯影格格網**。若另行打包為加padding的atlas，實際尺寸可不同，必須由metadata標示每格矩形與腳點；不可要求在上述精確邏輯尺寸內再硬塞padding。另外交付JSON映射，不能只靠檔名猜影格順序。

## 6. 製作順序與驗收

1. **視覺定調：** 先審概念板、色票、主角兩外觀、小所及自有臺北本所，確立視角與比例。
2. **垂直切片：** 完成P0場景、人物、家具、行動／HUD圖示與存檔模板，組成一個可讀的09:00工作畫面。
3. **可用性：** 用實際繁中文字、長案名、金額、疲勞小數、二十槽列表驗收；概念圖上的假字不作正式UI。
4. **擴充：** 完成五規模、合署、三城市、剩餘人物肖像與事件插圖；家具及角色優先共用。
5. **動畫與整合：** 檢查腳點、走路四向、坐姿接觸點、遮擋、32格拼接，並在1×／2×／3×縮放檢查清晰度。
6. **交付檢核：** ID與檔名對得上、尺寸正確、透明背景乾淨、源檔可開、CSV狀態更新；沒有音樂或音訊待製工作混入包中。
