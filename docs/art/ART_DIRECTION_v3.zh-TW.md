# 訴訟之神之路｜v0.4 靜態動作插畫

日期：2026-10-23。最新需求改為**每個動作一張圖片，增加女性主角版本，取消動畫**。文件沿用既有檔名；當前版本為 v0.4。

## 畫風與人物

以 PDF 概念圖的人物、服裝、家具材質、紙張與燈光細節為依據，製作精緻 2D 插畫。平滑輪廓、自然陰影與可辨認的臉、髮型、身形及衣著剪裁優先，不強迫像素格、最近鄰或極小尺寸。場景保留雨窗、暖燈、木質桌櫃與臺北生活感。

主地圖可用固定正交斜俯視與一致比例，動作圖則選一個清楚的插畫近景。男女版本表達相同動作，並保持同一環境與道具的可辨識性；不需要拼成分鏡或動作序列。

當前素材位於 [`assets/concept_v3/`](../../assets/concept_v3/)，機器可讀方向登錄為 `art_direction.json`。沿用的 52 張透明立繪包括 4 個主角工作／居家外觀、45 名員工及 3 名候選；辦公室與住家保留作背景。完整立繪不直接等於已拆好的臉髮、可換裝圖層或骨架。

## 單張 PNG 與視窗契約

- 路徑：`action_stills/male/<id>.png` 與 `action_stills/female/<id>.png`。
- [`manifest.json`](../../assets/concept_v3/manifest.json) 透過每個動作的 `images.male`／`images.female` 指向單圖；Godot 與 HTML 共用同一份引用。
- 使用新生成的全幅插畫，尺寸依原生 PNG 及清單記錄，不強制沿用 v0.3 的小尺寸影格。
- [`static_generation_manifest.json`](../../assets/concept_v3/static_generation_manifest.json) 保留生成提示、參照與雜湊；[`static_asset_validation.json`](../../assets/concept_v3/exports/static_asset_validation.json) 記錄實際圖片及男女覆蓋。
- [HTML 檢視器](../../assets/concept_v3/preview/index.html) 和 [Godot 展示](../../godot_demo/README.zh-TW.md) 顯示單張插畫，提供男性／女性外觀選擇及「繼續」、關閉、Esc。
- 圖片未經玩家操作就保持原樣；沒有逐幀、輪播、播放進度、時長、自動關閉，也不加入淡入、平移或縮放動畫。
- 每次視窗結束只發送一次完成訊號。畫面本身不扣款、不改能力、不推進日期；正式遊戲主流程須避免重複結算，早餐與分案仍不推進時段。

## 驗收與交付界線

1. **畫面品質：** 臉、手部、衣物與場景材質延續 PDF 概念圖；單張便能辨認動作，不用多格拼圖表示。
2. **男女完整性：** 14 項各有 male／female 獨立 PNG；女性主角不能由男性圖換色或同場配角代替，男女版本保持相同專業及表現。
3. **圖像正確：** 每個引用可解析，PNG 可解碼，人物沒有額外肢體或明顯手持物錯誤；圖片等比例顯示，臉及動作不被裁切。
4. **互動正確：** 開窗等待時不自換圖、不自關，切換性別只切換對應單圖；繼續、關閉及 Esc 不重複送出完成訊號，焦點可返回原控制。
5. **範圍清楚：** 目前是靜態插畫與小視窗展示；經營、案件及存檔系統仍待串接，人物可換裝骨架也未因此完成。
