# 訴訟之神之路｜v0.3 插畫素材與動作過場

日期：2026-10-23。這份文件取代 v0.2 的強制像素尺寸與低擬真 SVG 畫風；舊 PDF、CSV 及結構原型保留為歷史設計資料。

## 畫風依據

以既有 PDF 概念圖的人物、服裝、家具材質、紙張與燈光細節為品質參照，製作精緻 2D 插畫。角色要有可辨認的臉型、髮型、身形及服裝剪裁；場景保留雨窗、暖燈、木質桌櫃與臺灣城市生活感。平滑輪廓、自然陰影與細節優先，不強迫像素格、最近鄰或極小尺寸，也不再用幾何 SVG 人偶代替正式角色圖。

主地圖可使用固定正交斜俯視與一致比例，服務座位、人物及管理資訊的閱讀。動作過場是固定鏡頭的插畫近景，無須沿用地圖格；重點是人物好看、動作清楚、姿勢連續，不為投影規則犧牲概念圖的質感。

現行素材位於 [`assets/concept_v3/`](../../assets/concept_v3/)，機器可讀方向登錄為該目錄的 `art_direction.json`。舊 `docs/art/visual_style.json` 不更動，讓歷史 PDF 仍可重建；它的像素要求不約束本版。

## 人物與場景

- 主角工作／居家、男女外觀：目標四款透明立繪；性別不改變能力或規則。
- 員工與候選：目標四十八位可辨識人物立繪；不以換衣色、髮色或眼鏡冒充不同身份。
- 辦公室與住家：提供高畫質背景，作為工作與生活介面及過場展示的環境。
- 實際產出、尺寸、透明度與狀態以素材清單及驗證報告為準。目標數字不能直接當作已完成數字。

每名角色仍需穩定的 `AppearanceProfile` 與素材 ID 對應。同一角色的立繪、肖像及日後地圖人物不重新抽臉，職級與能力不決定身體模板。**透明整體立繪不等於五官可任意替換的圖層，也不等於已綁骨架。** 若本版提供的是完整 PNG，應如實標明；後續拆層、動作適配與四十五名 NPC 的完整動畫另行驗收。

## 十四個小視窗過場

一次動作播放約 2.8 秒：12 張姿勢影格，前 11 張各 200 毫秒，末張 600 毫秒。序列按動作連續性播放，不以平移或縮放單張靜態插畫代替肢體動作。

| write_brief | 寫書狀 | 落筆、書寫、抽頁、整理 |
| slack | 摸魚 | 伸懶腰、靠椅、看門口、放鬆 |

## 素材與展示格式

- 原始姿勢圖板留於 `raw/sheets/`，衍生 PNG 序列放在 `actions/<id>/frame_01.png` 等路徑。
- 同動作另提供動畫 WebP 與無音訊 MP4，方便快速播放；不加入音樂或音效。
- [`action_definitions.json`](../../assets/concept_v3/action_definitions.json) 是預定範圍；[`manifest.json`](../../assets/concept_v3/manifest.json) 列實際可用影格、尺寸、時長與缺項。
- [`exports/asset_validation.json`](../../assets/concept_v3/exports/asset_validation.json) 記錄素材檢查。缺少影格、WebP 或 MP4 的項目，不因已列出 ID 而標為完成。
- [HTML 檢視器](../../assets/concept_v3/preview/index.html) 可下載後直接開啟，或依[開啟說明](../../assets/concept_v3/preview/README.zh-TW.md) 使用本機伺服器。
- [Godot 展示說明](../../godot_demo/README.zh-TW.md)：使用 Godot 開啟專案根目錄的 `project.godot`，按 F5，以小視窗播放同一素材清單。

小視窗支援自然播完、略過、關閉及 Esc，結束訊號每次只發送一次；可使用減少動態／靜態預覽。它不自行扣款、改能力或推進日期。正式遊戲接入時，由主流程保管動作與唯一結算紀錄；早餐和分案仍不推進時段，略過也不能重抽或多結算。

## 驗收與交付界線

1. **畫面品質：** 實際顯示尺寸下，人物臉、衣服、手部及材質接近 PDF 概念圖；不能把低擬真佔位圖標作本版美術。
2. **動作成立：** 每支能看見姿勢或道具狀態改變，有開始、主動作及收尾；不可只是鏡頭移動或兩張不連續插畫閃爍。
3. **連續性：** 身份、衣著、手持物、鏡頭與背景不任意跳換；檢查穿插、額外肢體、忽然增減的物件及幀間跳動。
4. **素材正確：** 路徑可解析，PNG 尺寸一致，WebP／MP4 能解碼，時長與清單相符；透明立繪檢查 alpha 邊緣。
5. **互動正確：** 播完、略過、關閉、Esc 及快速重開後不殘留計時器，不重複送出完成訊號，焦點與按鈕仍可操作。
6. **範圍清楚：** 本版是實際插畫素材與可運行的動作過場展示，不是完整律師事務所經營遊戲，也沒有因此完成所有 NPC 的可換裝骨架動畫。

PDF 是靜態介紹媒介，不能代替動畫交付。檢查動畫請開啟檢視器、逐格序列或 WebP／MP4。v0.2 設計 ZIP 不包含本版位於 `assets/concept_v3` 的素材或 Godot 專案。
