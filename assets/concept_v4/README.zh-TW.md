# 訴訟之神之路｜本次新增素材包 v0.4

本包只收本次三項需求新增的 31 張原尺寸靜態 PNG：

- `actions/female/`：女性主角 14 張動作圖。
- `actions/male/`：男性主角 14 張動作圖。
- `scenes/home_after_work.png`：剛才生成的下班後家中場景，含在沙發休息的男主角。
- `results/win.png`、`results/loss.png`：勝訴／敗訴視窗，各一張，男女主角共用。

解壓縮後開啟根目錄 `index.html` 可離線瀏覽全部圖片，點選即可看原圖。每個動作以單張圖片表達，沒有動畫、自動換圖、影片或音樂。沒有收錄之前的角色立繪、舊辦公室／住家背景、概念簡報與舊素材包。

動作包含吃早餐、寫書狀、摸魚、面試新員工、查找資料、拍老闆馬屁、健身、看脫口秀、看法律講座影片、我只想睡覺、上電視節目、接受新聞採訪、客戶諮詢、分派案件。跳槽不在範圍內。

圖片沿用 PDF 概念圖的平滑 2D 插畫風格。女性主角使用黑髮馬尾造型，工作、正式場合與下班各有適合的服裝。勝敗圖是案件結果視窗，不代表破產或健康結局。

這些是合併完成的插畫 PNG；勝敗圖的邊框、標題及「繼續」外觀已畫在圖中，遊戲內按鈕事件需另行接上。`manifest.json` 提供檔名、用途、尺寸與 SHA-256；`generation_manifest.json` 保留生成來源；`SHA256SUMS` 可檢查解壓內容。
